# AZ-104 2026

Plataforma de estudo em React, Vite e Tailwind CSS 4, preparada para o GitHub Pages em `https://nunofbcastro.github.io/az104-2026/`.

## Executar localmente

Requer Node.js 20.19+ ou 22.12+.

```bash
npm install
npm run dev
```

Para criar a versão de produção: `npm run build`. O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente a pasta `dist` quando há uma alteração na branch principal.

## Perguntas

O banco importado contém as 657 perguntas existentes na pasta de origem e os respetivos recursos de imagem utilizados. Foram acrescentadas seis perguntas autorais, com explicação das opções e referências à documentação pública da Microsoft Learn. As perguntas novas são baseadas nos objetivos publicados no [guia oficial AZ-104](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104), atualizado para competências medidas desde 17 de abril de 2026.

As referências a documentação e outros materiais não significam que perguntas de terceiros tenham sido copiadas ou importadas. O banco de perguntas preexistente foi mantido como conteúdo fornecido pelo utilizador.
